# Modelo de apresentação

Esta pasta preserva o protótipo anterior da IANiza: escritório com integrantes, direção, cérebro ilustrativo, sessões, tarefas, rotinas, colaboração, entrevista de pedido e apresentação guiada.

Abra **http://127.0.0.1:4173/apresentacao/** após fazer login no projeto. O servidor principal entrega apenas os arquivos públicos permitidos dessa pasta.

- `src/`: código completo do modelo.
- `styles.css`, `direction.css`, `access.css`: estilos preservados.
- `assets/`: bundles, fontes e licenças.
- `docs/`: planejamento e decisões dos fluxos demonstrativos.
- `test/`: os 59 testes anteriores do protótipo.
- `capturas/`: capturas das versões de apresentação.
- `referencia/acesso-anterior.js`: interface anterior de pessoas e convites, para referência.

O protótipo continua usando as chaves de demonstração originais, por conta, no navegador. Seus dados não alimentam o projeto funcional. As referências antigas à raiz ou a `src/` nos documentos desta pasta descrevem a estrutura anterior à separação.

Use `npm run build` e `npm test` na raiz. Não existe uma segunda instalação ou banco de autenticação nesta pasta. O `codigo-beta/` continua separado e intacto.
