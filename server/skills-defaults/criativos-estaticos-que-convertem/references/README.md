# Imagens de Referencia

Coloque aqui os SEUS melhores anuncios (os que ja performaram bem) para a IA
usar como referencia de estilo ao gerar novos criativos.

Sugestao de exemplos para incluir:
- Um anuncio de "plaquinha" (pessoa segurando texto)
- Um anuncio de "dedo apontando" para o texto
- Um anuncio de "corpo caminhando" em direcao ao texto (escassez/evento)
- Um anuncio de "rosto close + texto ao lado" (garantia/retargeting)

Formato recomendado: PNG ou JPG, 1080x1080.
